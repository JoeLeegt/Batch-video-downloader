Buscando el motor…

El motor de descarga no está encendido

Esta página es la interfaz; las descargas las hace un programa en tu computadora.

  1. Descarga el proyecto desde GitHub e instala los requisitos (Python, yt-dlp y ffmpeg).
  2. Abre iniciar_web.bat en Windows, iniciar_web.command en macOS, o ejecuta python servidor.py.
  3. Deja abierta esa ventana. Esta página se conectará sola.

Si usas Safari, abre la dirección que muestra el motor (http://localhost:8765) en lugar de esta página.
